# @org/ui

Design system package (shadcn-style components + Tailwind preset) for shell and remotes.

## Install

```bash
npm install @org/ui
```

```ts
import { Button, Card } from '@org/ui';
import '@org/ui/styles.css';
```

Tailwind preset:

```js
import preset from '@org/ui/tailwind.preset';
```

## Build

```bash
npm install
npm run build
```
